# Rep1: Cadastro de pets

**Projeto:** `Fase1\ClasseListaMetodo\ClasseListaMetodo.Rep1.Pets`

## As classes

- [x] Crie uma classe `Pet` em `Pet.cs`, com nome, espécie e nível.
- [x] Ninguém de fora altera o nome, a espécie e o nível.
- [x] O `Pet` tem um método que devolve a descrição dele numa linha.

## O programa

- [x] O `Program.cs` tem uma lista de pets.
- [x] Menu em loop até sair: `1` Cadastrar / `2` Listar / `0` Sair.
- [x] **Cadastrar:** pede o nome. A espécie é fixa, "Cachorro", e o nível é 1.
- [x] **Listar:** mostra a descrição de cada pet.
- [x] Opção inválida no menu: avisa e volta para o menu.

## Partida de exemplo

O texto pode variar.

```
> 1
Nome do pet: Faísca

> 1
Nome do pet: Bolota

> 2
Nome: Faísca Espécie: Cachorro Nivel: 1
Nome: Bolota Espécie: Cachorro Nivel: 1

> 0
```

## Pronto

- [x] Você cadastra 2 pets, lista os dois e sai.

**Fora do pronto:** validação, salvar em arquivo, menu bonito.
